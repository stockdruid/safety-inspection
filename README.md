# 안전보건 순회점검 시스템

삼우기업주식회사 안전보건 순회점검 현장등록 웹사이트.
프론트엔드는 빌드 도구 없는 정적 HTML/CSS/JS, 백엔드는 외부 의존성 없는 Node.js 파일 서버.

## 두 가지 실행 방식

| 방식 | 접속 | 데이터 저장 | 여러 명 공유 |
|------|------|-------------|--------------|
| **정적 배포** (GitHub Pages 등) | 어디서나 URL로 | 각 기기 브라우저 `localStorage` | 안 됨 |
| **Node 서버** (`server.mjs`) | 같은 네트워크 또는 배포한 호스트 | 서버의 `data/` 파일 | 됨 |

프론트엔드는 시작할 때 `api/records` 응답 여부로 두 방식을 자동 판별하고, 헤더에 현재 저장 위치를 배지로 표시한다.

## 실행

정적 파일만 열어보려면:

```bash
python -m http.server 5180 --directory .
```

공유 서버까지 켜려면:

```bash
node server.mjs
```

기본 `0.0.0.0:5180`. 현장 휴대폰에서는 같은 네트워크에서 PC 사설 IP(`http://192.168.x.x:5180`)로 접속한다. 포트·호스트는 환경변수 `PORT`, `HOST`로 바꾼다.

## 구조

| 파일 | 역할 |
|------|------|
| `index.html` | 마크업 (시맨틱 구조, 접근성 속성) |
| `assets/styles.css` | 디자인 토큰 + 공공기관 스타일 + 반응형/인쇄 |
| `assets/app.js` | 화면 렌더링, 저장소 추상화(서버/로컬 자동 전환) |
| `server.mjs` | 정적 서빙 + REST API + 파일 저장 |
| `data/records.json` | 점검 기록 (자동 생성, Git 추적 제외) |
| `data/photos/` | 현장 사진 (자동 생성, Git 추적 제외) |

## API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/api/records` | 전체 기록 조회 |
| POST | `/api/records` | 기록 등록 (사진은 dataURL로 전송, 서버가 파일로 저장) |
| PATCH | `/api/records/:id` | 조치상태·조치내용 수정 |
| DELETE | `/api/records/:id` | 기록 및 사진 삭제 |

서버 측 처리:

- 쓰기 작업을 큐로 직렬화하고 임시 파일 → `rename`으로 교체해 동시 저장 시 파일 손상을 막는다
- 필수 항목·날짜 형식·위험유형·조치상태를 화이트리스트로 검증하고 문자열 길이를 제한한다
- 정적 경로에서 `..` 이탈과 `data/` 직접 접근을 차단한다 (사진은 `/photos/`로만 노출)
- 요청 본문 12MB, 사진 1장 4MB 상한

## 기능

- 점검 등록: 일자/담당/입회자/장소/위험유형/지적사항, 현장 사진 촬영 첨부
- 결과 분석: 위험유형별 관련 법조항, 위반 요지, 개선 조치 가이드 자동 표시
- 이력 대장: 당월 / 과거(월별 필터), 조치상태·조치내용 인라인 수정, 삭제
- 통계: 총 등록 / 조치완료 / 진행중 / 보류 건수
- 동기화: 새로고침 버튼, 탭 복귀 시 자동 갱신(10초 스로틀)
- 인쇄: 결과 분석, 이력 대장 각각 별도 출력 (버튼·관리열 제외)

## 반응형

| 폭 | 레이아웃 |
|----|----------|
| ~767px | 1단, 이력 표 → 카드 목록 전환, 입력 요소 16px(iOS 확대 방지), 터치 타깃 48px |
| 768~1023px | 1단, 이력은 표 + 가로 스크롤 |
| 1024px~ | 좌측 등록 폼(420px) + 우측 결과·이력 2단 |

## 사진 처리

첨부 사진은 업로드 전 브라우저에서 최대 변 1000px, JPEG 품질 0.7로 캔버스 압축한다. 로컬 모드에서는 `localStorage` 용량 한계가 있어 저장 실패 시 등록이 취소되고 안내가 표시된다.

## 보안

현재 인증 기능이 없다. 서버에 접근 가능한 사람은 누구나 기록을 읽고 쓸 수 있으므로, 사내망 또는 VPN 안에서만 실행할 것. 공개 인터넷에 노출하려면 인증(공유 비밀번호 또는 SSO)과 HTTPS를 먼저 붙여야 한다.

## 법령 데이터

`assets/app.js`의 `RISK_DB` 객체에서 위험유형별 법조항·요지·조치 가이드를 관리한다. 항목 추가 시 `index.html`의 `#category` 옵션과 `server.mjs`의 `CATEGORIES` 배열에도 같은 key를 추가할 것.
